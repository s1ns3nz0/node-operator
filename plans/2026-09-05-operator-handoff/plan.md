# Operator handoff plan

1. Read the current task evidence, checked-in operations runbook, session
   script, and prior handoff material.
2. Write one non-sensitive Korean handoff that separates verified history,
   cost-suspended resources, unfinished work, and ordered recovery steps.
3. Validate repository structure, shell-script contract, and documentation
   whitespace.
4. Obtain an independent clean-room review of the task bundle, diff, and check
   results; correct any findings before integration.
